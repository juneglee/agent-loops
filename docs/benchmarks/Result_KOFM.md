# KOFM — 한국어 파일 관리 요청 300건, 코어 루프 7종

한국어 파일 정리·검색·편집 요청 300건을 코어 루프 7개로 돌렸다. 데이터셋은 공개하지 않아서 여기에는 집계만 적는다. 실패 사례는 [Analysis_KOFM](Analysis_KOFM.md) 에 따로 모았다.

## 지표

- 성공률 (Success Rate, SR): 최종 워크스페이스와 사용자에게 보인 답이 요청대로인 케이스 비율. 순위는 이 값으로 매긴다.
- 되묻기율 (Ask Rate): 요청만으로는 무엇을 할지 알 수 없는 단일 과제 23건 중 되물은 비율. [AskBench](https://arxiv.org/abs/2602.11199) 의 Vague Ask Rate 와 같은 방식이다. 되물은 경우는 성공률에 넣지 않는다.
- 정상 종료율 (Completed): 모든 턴이 `success` 로 끝난 케이스 비율. [AgentBench](https://arxiv.org/abs/2308.03688) 의 Completed 처럼 결과가 맞았는지와 상관없이 루프가 스스로 끝냈는지만 본다. 스텝 상한, 재시도 상한, 형식 오류, 빈 응답으로 끝난 턴이 하나라도 있으면 빠진다.
- 실행률 (Tool Invocation Rate): 도구를 한 번이라도 부른 케이스 비율.
- 스텝 (Avg. Steps): 케이스당 평균 스텝 수.
- LLM 호출 (LLM Calls): 케이스당 평균 LLM 호출 수.
- 도구 호출 (Tool Calls): 케이스당 평균 도구 호출 수.
- 중복 호출 (Duplicate Calls): 같은 인자로 같은 도구를 다시 부른 횟수의 케이스당 평균.
- LLM 오류 (LLM Errors): LLM 호출이 한 번 이상 실패한 케이스 수. 대부분 120초 타임아웃이고 HTTP 400 이 6건 있었다.

### 성공 판정

- 요청한 파일을 전부 처리해야 한다.
- 요청 밖의 파일을 옮기거나 지우거나 덮어쓰면 실패다.
- 요청에 나온 폴더가 이미 있으면 그 폴더를 써야 한다. 없으면 `backup/` 처럼 다른 이름으로 만들어도 된다.
- 답이 필요한 요청은 사용자에게 보이는 답이 있어야 하고 내용이 맞아야 한다.
- 과정은 보지 않는다. 스텝 상한에 걸렸어도 최종 상태가 맞으면 성공이다.
- 요청한 삭제는 해내면 성공이다.
- 카톡 전송이나 인쇄처럼 도구로 할 수 없는 요청은 못 한다고 답해야 성공이다.
- 분명한 요청에 되물으면 실패다.
- 멀티턴은 세 턴을 끝까지 해내야 성공이다. 둘째·셋째 턴은 앞 턴에서 루프가 만든 상태를 기준으로 보므로, 첫 턴에 `백업/` 대신 `backup/` 을 만들었어도 이후 턴에서 계속 그 폴더를 썼으면 인정한다.
- 멀티턴에서 중간에 포기했거나, 있는 파일을 없다고 했거나, 답이 필요한 턴에 답이 없으면 실패다.

## 요약

성공률은 reflexion 61.7%, dfsdt 61.3%, react 58.3% 순이다. 그다음이 adapt(52.0%)와 plan_and_act(47.7%)이고, plan_and_execute 와 plan_and_solve 는 한참 아래에 있다.

단일만 보면 reflexion 과 dfsdt 가 앞서고, 멀티에서는 react 가 68.0% 로 가장 높다. adapt 는 압축을 푸는 대화에서 특히 약해서(17건 중 4건 성공) 멀티가 단일보다 낮다.

모호한 요청에는 reflexion 과 adapt 가 가장 자주 되물었고, plan_and_execute 는 한 번도 되묻지 않았다.

plan_and_solve 는 정상 종료율이 98.0% 인데 성공률은 11.3% 다. 계획을 한 번 세워 그대로 실행하고 끝나니 루프는 거의 항상 정상 종료한다. 하지만 조회 요청에 답을 쓰지 않고, 공백이나 괄호가 든 파일명에서 명령이 깨져도 다시 시도하지 않는다. plan_and_execute 는 실행은 하는데 턴 끝에 답을 내지 않는 일이 많아서 멀티 50건 중 3건만 성공했다.

LLM 오류는 react, reflexion, adapt 에서 많이 났다. 오류가 난 케이스를 빼고 다시 계산해도 reflexion 65.8%, dfsdt 61.1%, react 61.1% 로 위 세 루프가 모여 있는 모양은 같다.
